## 📋 版本概述

v1.1.0 在 v1.0.0 的完整闭环之上，重点解决三类问题：判定口径与告警噪音、设置保存的可靠性、以及日常运维的操作便利性。

判定侧把计划匹配窗口改为对称区间，未执行告警按计划周期隔离，长周期计划回溯上限放宽到 8 年，并把手动执行从计划匹配中排除；告警侧不再因主机离线静默清除漏执行告警，关闭去重后恢复 1 小时重复抑制；设置侧改为按区块与字段合并保存，保存保留天数后立即触发清理；操作侧新增执行记录与告警批量清空、计划补录与锁定解除，并顺带修复了心跳绕过离线阈值等问题。

---

## ✨ 新增特性

### 任务计划补录与锁定

- 采集到的计划文本无法解析为 cron 时（如 Windows「开机时」），任务列表展示「计划未识别」，该任务不参与未执行判定
- 任务详情可通过铅笔补录 5 段 cron；勾选「仅服务端判定」后计划只写服务端、不下发 Agent，后续上报不再覆盖
- 列表展示「服务端判定」、详情展示「仅服务端判定」，并提供「解除锁定」入口，恢复由 Agent 上报覆盖

### 执行记录与告警批量清空

- 「执行记录」与「告警中心」工具栏在导出右侧新增「清空」按钮，按当前筛选结果批量删除
- 清空操作写入审计，目标列统一为清除条数（如「13 条」）
- 清空执行记录时，确认框提示相关任务会在下次巡检重新判定、可能重新产生未执行告警

### 交互与脚本

- 执行计划下发选项改为轻量复选按钮，说明文案收进项目统一的悬浮提示，不再使用滑动开关
- 新增 Windows 批处理脚本 `scripts/veeam-backup.bat`：关闭 Veeam 相关进程与 VSS 服务后重启服务、按作业 GUID 触发一次备份，并把开始/结束时间写入状态文件

## 🐛 Bug 修复

- **计划匹配窗口改为对称区间**：执行记录落在「计划时刻 ± 窗口」内才算本次执行，晚于窗口判定为未按时执行且不回填，消除计划时刻前的规律性误报
- **未执行告警按计划周期隔离**：只有同一计划周期的执行记录才会恢复该告警，下一次计划的执行不再顺手关闭上一次的漏执行告警
- **发送记录保留独立生效**：三个保留天数分别清理，不再被其它保留项阻断
- **主机离线不再静默清除未执行告警**：离线期间只恢复备份失败告警，漏执行告警保留到恢复在线后继续判定
- **长周期计划可回溯**：计划时间搜索上限提升到 8 年，覆盖月度、季度、年度与闰年 2 月 29 日
- **手动执行不再掩盖漏跑**：计划匹配只认非手动触发的执行记录，人工跑一次不会让计划看起来已按时完成
- **关闭去重恢复 1 小时抑制**：同一任务/主机的同类型告警最多每小时重复创建并推送一次，避免巡检周期内反复落库
- **保存保留设置后立即清理**：三个保留天数变化保存后立即触发一次清理，其余时间仍保持每小时最多一次
- **备份参数保存改为合并**：请求体只提交部分字段时，未提交字段保持原值，不再把其它区块重置为默认；`section` 为已知区块时只应用该区块字段
- **主机状态统一按上报阈值判定**：WebSocket 断开只关闭连接，不再直接写离线状态或发心跳离线告警，异常/离线由 3/6 分钟阈值决定
- **前端任务类型补齐 `scheduleLocked`**：修复锁定标识与解除入口的类型检查报错
- **清空操作口径统一**：执行记录与告警清空的审计目标改为条数，审计日志清空弹窗补充当前筛选条数

## 🔄 API 变更

- 新增 `POST /api/backup/executions/clear`：请求体 `{"ids":[...]}`，返回 `deleted`，权限 `backup.executions.manage`
- 新增 `POST /api/backup/alerts/clear`：请求体 `{"ids":[...]}`，返回 `deleted`，权限 `backup.alerts.manage`
- 任务列表与详情新增 `scheduleParsed`、`scheduleDisabled` 字段，用于标识计划是否可用于判定
- `PUT /api/backup/tasks/{id}/schedule` 新增 `serverOnly`（仅服务端判定）与 `unlock`（解除锁定）参数
- `PUT /api/backup/settings` 改为按区块与字段合并保存，未提交字段保持原值（兼容整包提交）
- 权限说明更新为「删除、清空与导出执行记录」「恢复、删除、清空与导出告警事件」

接口总数由 89 增至 **91**（Swagger 已同步）。

## 🔄 升级说明

1. 直接替换后端二进制与前端产物（或更新 Docker 镜像）即可，无需数据库迁移
2. **历史未执行告警**：升级前生成的告警消息只有时分、没有日期，无法按计划周期自动恢复，建议人工恢复或清空后由新版本重新判定
3. **主机离线感知**：WebSocket 断开不再 15 秒直接判离线，改为按「上报超时 / 离线阈值」（默认 3 / 6 分钟）判定；如需更快感知可后续增加快速离线开关
4. **关闭告警去重**：关闭后保留 1 小时重复抑制，同一任务/主机同类型告警最多每小时提醒一次
5. **清空执行记录**：删除最新执行记录后，相关任务可能在下次巡检重新判定为未执行并产生告警，属预期行为
6. Agent 无需升级，本次未变更上报协议
